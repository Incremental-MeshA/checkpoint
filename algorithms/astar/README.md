# A* из MeshA*

Каталог `paper/` содержит поиск, генераторы преемников, OPEN, CLOSED и пул узлов из [MeshA*, ревизия 12574ff](https://github.com/PathPlanning/MeshAStar/tree/12574ff03d8d61ac153b4e4224eac2229a9577e1). Лицензия авторов находится в `paper/LICENSE.txt`.

`astar.cpp` соединяет авторский поиск с текущей наблюдаемой картой стенда. Оба варианта используют вес 1, точную конечную позу и обычную проверку столкновений. Между запросами очищаются посещённые биты CLOSED, сам буфер рассчитан на реальные размеры карты. Изменения карты видны через общую сетку. Счётчики и трасса привязаны к фактическим извлечениям из OPEN, раскрытиям и проверкам клеток.

Для восстановления пути сохраняется ID пройденного примитива. Это поддерживает пользовательские наборы, в которых несколько примитивов соединяют одинаковые позы. Для car16 таблица `base_mesh_info.txt` читается до начала замеров. D* Lite и MPGAA* используют её переходы и Finals, а стенд строит входящие рёбра для инкрементального ремонта. Для пользовательского набора без авторской таблицы те же структуры создаются из префиксов следов.

Стоимость найденного маршрута в журнале повторно вычисляется из исходных длин. Внутри A* сохранены `float` и евклидова эвристика авторов, у двух инкрементальных поисков — точная сумма длин, нижняя оценка с масштабированием и развязка по числу рёбер.
