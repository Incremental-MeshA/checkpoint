# MPGAA* с ленивым ограничением эвристики

Вариант `mpgaa_lazy` работает на mesh. Цель фиксирована, старт может меняться между запросами. Поиск, повышение эвристики в закрытых позах и проверка сохранённого хвоста общие с MPGAA*. Меняется способ восстановления согласованности после освобождения клеток.

## Построение оценки

Пусть примитив стоимости `c` идёт из `u` в `v = u + Δ`, а клетка следа имеет координаты `q = u + d`. Программа использует восемь линейных проекций с векторами нормы не больше единицы. Осевые проекции единичные, диагональные компоненты равны ±181/256. Для пары направлений `a,b` вычисляется

```
K[b,a] = min (floor(256*c)/256 - a·d - b·(Δ-d))
```

Минимум берётся по всем примитивам и всем клеткам их следов. У внутренней конфигурации mesh смещение `d` общее. Для каждого `b` остаток минимизируется по списку завершений один раз и используется для всех восьми `a`. Начала и концы примитивов учитываются отдельно. Это одноразовая работа с шаблонами движений. Карта и старт в неё не входят.

Для каждой освобождённой клетки выбирается направление `b`, максимизирующее `b·(goal-q)`. Клетки с одинаковым `b` образуют сектор. При получении пакета записывается таблица

```
T[b,a] = min по клеткам q сектора (a·q + b·(goal-q) + K[b,a])
```

Предел в позе `x` — минимум по непустым секторам от `max_a(T[b,a] - a·x)`. Его вычисление требует до 64 сравнений направленных оценок на пакет независимо от числа освобождённых клеток. При чтении выученной метки применяются только таблицы новее её версии. Результат ограничивается снизу исходной эвристикой `H(x)` и сохраняется вместе с новой версией. Обучение при следующем успешном поиске может снова поднять метку. Пакеты с одними блокировками обходятся без таблицы. История хранится до конца эпизода, по 512 байт полезных данных на пакет освобождений после начала обучения.

## Согласованность

Для каждого примитива, который открылся через клетку `q`, значение его сектора в исходной позе `u` не превосходит `c + H(v)`. Это следует подстановкой `q = u+d` в формулу для `K`: после сокращения остаётся `c + b·(goal-v)`. Округление стоимости направлено вниз. Минимизация по клеткам сектора может дополнительно ослабить оценку. Применение максимума по направлениям сохраняет верхнее ограничение, поскольку оно выполняется для каждого направления.

Каждая аффинная функция имеет наклон с нормой не больше единицы. Их минимумы и максимумы согласованы на ранее доступных рёбрах, стоимость которых ограничивает евклидово смещение позы. Поэтому обновление `max(H, min(h_old, предел))` сохраняет согласованность на этих рёбрах. На открывшемся ребре оно даёт `h_new(u) ≤ c + H(v) ≤ c + h_new(v)`. На удалённых рёбрах проверка не требуется. Длина предела представляется точным числом с шагом 1/256, вторичный компонент стоимости предела равен нулю. Отложенное вычисление следует порядку пакетов. Успешный возврат сохранённого хвоста по-прежнему требует проходимости и равенства адаптивной оценки его стоимости.

## Запуск профиля long

```powershell
foreach ($p in '0.1','0.5','1','5') {
    python -m bench run --profile long --algorithm mpgaa_lazy --change-percent $p --output "runs/lazy-long/navigation-$p"
}
foreach ($r in 25,50,100,200) {
    python -m bench run --profile long --algorithm mpgaa_lazy --config config/visibility.json --radius $r --output "runs/lazy-long/visibility-$r"
}
```
